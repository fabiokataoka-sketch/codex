Lead paragraph — used to introduce sections. Muted color, loose leading, max 60 characters per line for comfortable reading.

body · Inter · --al-text-md

Body copy is set in Inter at 16px with 1.5 line height. It stays quiet and legible so the display type can do the shouting. Inline links pick up the accent on hover.
